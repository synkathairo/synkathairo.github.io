## Definition

Given a set $D$ and a subset $S \subseteq D$, $S$ is **effectively enumerable** iff there is an _effective procedure_ which, when given an object $x \in D$ will eventually answer "yes" if $x \in S$, and will eventually answer "no" or never terminate if $x \notin S$.
