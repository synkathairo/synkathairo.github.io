## Definition

A **metric space** $(X,d)$ is a set $X$ together with a distance function $d : X \times X \to [0,\infty)$ called a [[metric]] (satisfying certain axioms) defined upon it.

## Notes

- can always define a _Borel measure_ in a _metric space_ using the [[σ-algebra|sigma algebra]] generated by [[open set|open sets]].
- _metric spaces_ are [[Hausdorff space|Hausdorff]] ($T_2$)
