## Definition
Define [[decision problem|language]] $L'$ as **NP-hard** if $L \leq_p L'$ for every $L \in$ [[class NP|NP]]. (polynomial-time reduction from $L$ to $L'$)

(see [[class NP|NP]], also note that $\leq_p$ means [[polynomial-time Karp reducible|polynomial-time reduction]])
