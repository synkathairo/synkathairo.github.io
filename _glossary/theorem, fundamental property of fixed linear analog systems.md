## Theorem
If $S$ is a [[fixed system|fixed]] (time-invariant) linear [[continuous time state equations|analog]] (continuous-time) system then the *zero-state response*
$$S\{e^{st}\} = H(s) \{e^{st}\}$$
where $H(s)$ is the [[transfer function]]
