## Definition
**Manifold optimization** is concerned with the optimization problem
$$\min_{x \in \mathcal{M}}\quad f(x)$$ where $\mathcal{M}$ is a [[Riemannian manifold]] and $f$ is a real-valued function on $\mathcal{M}$, which can be non-[[smooth function|smooth]].
