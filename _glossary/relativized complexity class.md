## Definition (_relativized complexity class_)

For _complexity class_ and [[decision problem|language]] $A$, let **relativized complexity class** $C^A$ be the languages [[effectively decidable|decidable]] by $C$-machines with [[oracle machine|oracle]] access to $A$.

## Definition (_relativized world_)

A **relativized world**, i.e. a world relative to [[oracle machine|oracle]] $A$, is one in which every machine has access to the same oracle.
