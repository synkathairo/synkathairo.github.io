## Definition
Define the class $\mathbf{EXP} = \cup_{c \geq 1} \mathbf{DTIME}(2^{n^c})$.

## Notes
- exponential-time analog of [[class P|P]]
- $\mathbf{P} \subseteq \mathbf{NP} \subseteq \mathbf{EXP}$
